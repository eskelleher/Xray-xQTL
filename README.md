# Xray-xQTL
this respository includes all scripts required for QTL analysis of Xray tolerance in Drosophila, as well as associated RNA-seq data of radiotolerant and radiosensitive strains

Major steps of the pipeline

1) SNP calls and QC

2) Haplotype frequency estimates

3) QTL mapping and haplotype phasing

4) Identification of candidate variants

5) RNAseq
